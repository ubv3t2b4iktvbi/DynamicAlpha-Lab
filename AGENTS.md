### How to use skills
- Discovery: Project-local skill bodies live under `.agents/skills/project/`.
- Trigger rules: Use one of these skills when the user names it explicitly or when the task clearly matches its description.
- Progressive disclosure: Read the `SKILL.md` first, then load only the additional files that are needed for the current task.
- Context hygiene: Keep the skill body concise and prefer code, nearby READMEs, scripts, and run artifacts over repeated prose.
- Promotion hygiene: When a maintenance skill should stay durable across toolchains, mirror it under `.claude/skills/project/` before treating it as fully promoted.
