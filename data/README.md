# data

这个目录用于存放因子库相关数据资产，而不是 benchmark 运行结果。

当前结构：

- `factorlib/raw/`
  - 原始候选因子、未审查结果、待整理资产
- `factorlib/selected/`
  - 经过筛选和人工审核后准备长期保留的因子资产

## 使用约定

- `raw/` 适合放：
  - 批量候选因子草案
  - 跨任务汇总前的中间结果
  - 尚未通过专家审核的结果
- `selected/` 适合放：
  - 已通过人工审核的稳定因子
  - 计划作为后续默认库的因子清单

## 注意

- 不要把临时 benchmark 输出直接放进这里，应该放在 `runs/`
- 如果一个因子尚未通过 `expert_review_template.md` 对应的人审流程，不建议直接进入 `selected/`
